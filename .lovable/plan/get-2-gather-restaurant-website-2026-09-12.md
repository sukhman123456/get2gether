# Get 2 Gather Restaurant Website

## What I’ll build
- Replace the blank home page with a polished, responsive single-page restaurant and cafe website.
- Follow the requested flow: immersive food-led opening, brand statement, about, services, menu placeholder, featured food, gallery, reviews summary, location, contact, and footer.
- Add sticky desktop and mobile navigation, section highlighting, smooth scrolling, accessible menus, touch-friendly calls to action, gallery lightbox controls, and a compact mobile action bar.
- Use only confirmed business information. Menu content, map, and missing restaurant-specific details will remain clearly marked placeholders rather than invented claims.
- Create a cohesive warm editorial system with espresso, terracotta, ivory, beige, charcoal, serif headings, subtle motion, restrained shadows, and consistent image treatment.
- Generate a small optimized set of warm restaurant/food photographs because no actual Get 2 Gather photos were supplied; these can be replaced later.
- Add page-specific search and sharing metadata for Get 2 Gather in Gurdaspur.

## Technical details
- Keep the experience lightweight with React, Tailwind utilities, CSS transitions, IntersectionObserver-based reveals, and no heavy animation library.
- Build reusable navigation, section, menu placeholder, gallery, lightbox, and action components.
- Respect reduced-motion settings, keyboard navigation, focus states, semantic landmarks, responsive image behavior, and lazy loading below the fold.
- Verify the final page at desktop and mobile sizes, test navigation and lightbox interactions, and confirm the project has no build or runtime errors.
